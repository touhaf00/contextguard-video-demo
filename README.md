# Tiny Calculator

A small calcualtor library for Python, used as a demo repository for [ContextGuard](https://github.com/touhaf00/contextguard).

This repository is intentionally imperfect: it contains a few small, deliberate defects (a failing test, a typo, thin documentation) so that ContextGuard has something real to investigate.

## Run the tests

```bash
python -m unittest -v
```
